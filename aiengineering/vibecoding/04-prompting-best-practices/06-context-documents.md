# 06 - Regularly Update Your Context Document (e.g. CLAUDE.md / AGENTS.md)

## 🎯 Definisi & Konsep
**Regularly Update Context Document** adalah proses memperbarui file dokumentasi konteks utama repositori secara berkelanjutan setelah menyelesaikan sesi koding, diskusi arsitektur, atau penemuan bug penting.

Jika dalam sebuah diskusi Anda menemukan solusi untuk suatu masalah atau menyepakati konvensi baru, mintalah AI memperbarui `CLAUDE.md` atau `AGENTS.md` agar pengetahuan tersebut tidak hilang saat chat di-reset.

---

## 🛠️ Alur Pembaruan Konteks Otomatis

```text
Sesi koding hari ini telah selesai dan kita telah berhasil memecahkan masalah CORS dan penanganan token JWT.
Tolong perbarui file `AGENTS.md` di bagian "Troubleshooting & Auth Guidelines" dengan menambahkan pelajaran dan aturan yang baru saja kita sepakati ini.
```
