# 04 - Give AI Mockups, Reference Files and Material That Can Help It

## 🎯 Definisi & Konsep
**Provide Mockups & References** adalah menyertakan berkas pendukung—seperti file dokumen arsitektur, gambar UI mockup, skema OpenAPI/Swagger, atau file contoh dari repositori lain—ke dalam sesi percakapan dengan AI.

AI multimodalkini mampu mengekstrak tata letak dari gambar dan tipe data dari file referensi secara presisi.

---

## 💬 Contoh Prompt Integrasi Bahan Rujukan

```text
Saya telah mengunggah file screenshot desain navbar [navbar_design.png] dan file rujukan tema `src/theme/colors.ts`.

Tolong buatkan komponen `Navbar.tsx` yang secara presisi mengikuti:
1. Spasi dan susunan ikon sesuai gambar `navbar_design.png`.
2. Variabel warna dari file `src/theme/colors.ts`.
```
