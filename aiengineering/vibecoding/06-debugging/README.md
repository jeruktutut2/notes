# Modul 06: Debugging

> **"Let AI Debug, But Understand what Went Wrong"** — Ketika terjadi kesalahan, tempelkan error dan kode relevan, lalu minta AI menjelaskan permasalahannya. Jangan langsung menerima perbaikan begitu saja—pastikan Anda memahaminya.

---

## 📌 Definisi Umum
**Debugging** dalam Vibe Coding memanfaatkan kemampuan pemrosesan log & stack trace dari AI untuk mengidentifikasi dan memecahkan bug dengan cepat. Namun, prinsip utamanya adalah **memahami akar masalah**, bukan sekadar menempelkan patch tanpa paham penyebabnya.
