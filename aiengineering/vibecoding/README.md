# Panduan Belajar Vibe Coding (roadmap.sh/vibe-coding)

Selamat datang di repositori pembelajaran **Vibe Coding** yang dirancang berdasarkan kurikulum resmi dari [roadmap.sh/vibe-coding](https://roadmap.sh/vibe-coding).

Vibe Coding adalah seni dan metodologi berkolaborasi secara efektif dengan AI Coding Assistants (seperti Claude Code, Cursor, Antigravity, GitHub Copilot, dsb.) untuk membangun perangkat lunak berkualitas tinggi dengan cepat, terstruktur, dan aman.

## 💡 Prinsip Utama Vibe Coding

1. **AI adalah Penggerak, Anda adalah Arsitek & Pilot**: Jangan biarkan AI berasumsi tanpa arahan spesifikasi yang jelas.
2. **Context is King**: Berikan AI konteks yang bersih, relevan, dan terstruktur.
3. **Fail Fast, Commit Often**: Eksekusi perubahan kecil per fitur, lakukan pengujian, dan simpan dalam Git commit secara berkala.
4. **Keamanan & Standar Utama**: Tetapkan aturan styleguide, linting, dan proteksi kredensial sejak awal.
