# Modul 02: Tech Stack and Coding

> **"Establishing Standards Early is Important"** — Tinjau hasil awal AI (coding patterns, styles, arsitektur). Jika kebiasaan buruk tidak ditangkap sejak dini, AI akan memperkuatnya di setiap iterasi.

---

## 📌 Definisi Umum
**Tech Stack and Coding** membahas bagaimana memilih ekosistem teknologi yang tepat dan menetapkan standar pengkodean (coding guidelines, modulariasi, serta refactoring) agar kode yang diproduksi oleh AI tetap bersih, terstruktur, dan mudah dipelihara.

---

## 📄 Daftar Sub-Topik & Panduan Praktis

1. [📂 `01-popular-tech-stack.md`](./01-popular-tech-stack.md)
   - Pilih tech stack populer daripada stack baru/niche (karena LLM terlatih pada data populer).
2. [📂 `02-coding-preferences-doc.md`](./02-coding-preferences-doc.md)
   - Dokumentasikan preferensi gaya dan standar coding untuk AI (`AGENTS.md`, `styleguide.md`).
3. [📂 `03-modular-code.md`](./03-modular-code.md)
   - Minta AI menjaga kode tetap modular dengan file/modul kecil yang terisolasi.
4. [📂 `04-review-and-refactor.md`](./04-review-and-refactor.md)
   - Minta AI melakukan audit review & refactoring codebase secara rutin.
5. [📂 `05-use-community-skills.md`](./05-use-community-skills.md)
   - Manfaatkan custom skills, MCP, atau extension yang dibuat oleh komunitas.

---

## 💡 Kunci Penting
- Jangan biarkan file membengkak hingga > 300 baris.
- Paksa refactoring sebelum menumpuk fitur baru!
