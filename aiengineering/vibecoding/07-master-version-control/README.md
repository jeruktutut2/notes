# Modul 07: Master Version Control

> **"Commit Often, With Clear Messages"** — Setelah setiap fitur atau perbaikan berfungsi, buatlah commit. Minta AI menyarankan pesan commit yang jelas. Ini memberi Anda titik aman (checkpoint) untuk kembali jika terjadi kesalahan di kemudian hari.

---

## 📌 Definisi Umum
**Master Version Control** adalah pengintegrasian Git secara ketat ke dalam alur kerja Vibe Coding. Git bertindak sebagai jaring pengaman (safety net) utama saat bekerja dengan AI.

---

1. [📂 `01-frequent-git-commits.md`](./01-frequent-git-commits.md)
   - Gunakan `git commit` secara teratur (misal: setelah setiap tugas AI sukses).
2. [📂 `02-clean-git-slate.md`](./02-clean-git-slate.md)

3. [📂 `03-git-revert-over-ai.md`](./03-git-revert-over-ai.md)

   - Minta AI menangani tugas Git dan GitHub CLI (gh) Anda.
