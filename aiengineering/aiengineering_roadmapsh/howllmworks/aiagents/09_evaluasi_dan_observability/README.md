# Implementasi Point 9: Evaluasi & Observability

Modul ini berisi implementasi cara mengukur dan memantau performa AI Agent.

## Daftar File
1. `1_basic_evaluation.py`: Evaluasi output agent secara otomatis menggunakan LLM-as-Judge.
2. `2_logging_dan_tracing.py`: Logging setiap langkah agent untuk debugging dan monitoring.

## Urutan Eksekusi

```bash
python 1_basic_evaluation.py
python 2_logging_dan_tracing.py   # Tidak butuh API key
```

### Cara Instalasi Library
```bash
pip install openai
```
