# Implementasi Point 2: Prompt Engineering

Modul ini berisi teknik-teknik prompt engineering untuk berkomunikasi secara efektif dengan LLM.

## Daftar File
1. `1_basic_prompting.py`: Memahami peran System/User/Assistant dan cara menyusun prompt yang baik.
2. `2_chain_of_thought.py`: Teknik Chain-of-Thought (CoT) untuk meningkatkan kemampuan reasoning LLM.
3. `3_structured_output.py`: Memaksa LLM menghasilkan output terstruktur (JSON).

## Urutan Eksekusi

```bash
python 1_basic_prompting.py
python 2_chain_of_thought.py
python 3_structured_output.py
```

### Cara Instalasi Library
```bash
pip install openai
```
