# Implementasi Point 7: Multi-Agent Systems

Modul ini berisi implementasi sistem multi-agent — beberapa agent yang bekerja sama
untuk menyelesaikan tugas kompleks.

## Daftar File
1. `1_sequential_agents.py`: Agent berantai/pipeline (Penulis → Editor → Reviewer).
2. `2_supervisor_agent.py`: Supervisor agent yang mendelegasikan tugas ke agent spesialis.

## Urutan Eksekusi

```bash
python 1_sequential_agents.py
python 2_supervisor_agent.py
```

### Cara Instalasi Library
```bash
pip install openai
```
