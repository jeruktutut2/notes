# 💡 MODUL 01: MULTIMODAL AI USECASES

Submodul ini mencakup 6 implementasi skrip Python untuk kasus penggunaan (*use cases*) Multimodal AI sesuai diagram roadmap.sh/ai-engineer.

## 📂 Daftar Skrip Python

| No | File | Topik & Cakupan Demonstrasi |
|----|------|-----------------------------|
| **01** | `01_image_understanding.py` | Visual Question Answering (VQA), OCR Dokumen, Bounding Box & Base64 Payload |
| **02** | `02_image_generation.py` | Latent Diffusion Sampling Loop, Prompt Conditioning & ControlNet Structural Edge |
| **03** | `03_video_understanding.py` | Keyframe Uniform Sampling, Cross-frame Attention & Temporal Video QA |
| **04** | `04_audio_processing.py` | STFT Waveform Processing, Log Mel-Spectrogram & Sound Event Classification |
| **05** | `05_text_to_speech.py` | SSML Prosody Parsing, Grapheme-to-Phoneme, Acoustic Model & Neural Vocoder |
| **06** | `06_speech_to_text.py` | Whisper Audio Encoder-Decoder Architecture, Transkripsi & Ekspor Subtitle SRT |

## 🚀 Cara Menjalankan

```bash
python3 01_multimodal_usecases/01_image_understanding.py
python3 01_multimodal_usecases/02_image_generation.py
python3 01_multimodal_usecases/03_video_understanding.py
python3 01_multimodal_usecases/04_audio_processing.py
python3 01_multimodal_usecases/05_text_to_speech.py
python3 01_multimodal_usecases/06_speech_to_text.py
```
