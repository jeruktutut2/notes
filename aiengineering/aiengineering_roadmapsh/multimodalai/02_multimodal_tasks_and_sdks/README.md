# 🧱 MODUL 02: MULTIMODAL AI TASKS & SDKS

Submodul ini mencakup 7 implementasi skrip Python untuk SDK, API, dan Framework Multimodal AI sesuai diagram roadmap.sh/ai-engineer.

## 📂 Daftar Skrip Python

| No | File | Topik & Cakupan Demonstrasi |
|----|------|-----------------------------|
| **01** | `01_openai_vision_api.py` | GPT-4o Vision SDK, Multi-image analysis, Detail modes (`low`/`high`) & Base64 |
| **02** | `02_dalle_api.py` | DALL-E 3 API, Prompt Revision Inspector & parameter kualitas visual |
| **03** | `03_nanobanana_api.py` | NanoBanana API Client SDK & REST Multimodal Custom Endpoints |
| **04** | `04_whisper_api.py` | OpenAI Whisper API Transkripsi & Penerjemahan Bahasa Otomatis |
| **05** | `05_huggingface_models.py` | Hugging Face Transformers: CLIP Zero-Shot, BLIP Captioning & Florence-2 |
| **06** | `06_langchain_multimodal.py` | LangChain Framework: ChatPromptTemplate, Multimodal Message & Chains |
| **07** | `07_llamaindex_multimodal.py` | LlamaIndex Framework: MultiModalVectorStoreIndex & Cross-modal Query Engine |
