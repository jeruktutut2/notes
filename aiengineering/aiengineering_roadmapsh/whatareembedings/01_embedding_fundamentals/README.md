# 01. EMBEDDING FUNDAMENTALS & VECTOR SPACE

Modul ini mempelajari fondasi matematis dari **Embeddings**, cara data spasial dimensi tinggi disimpan, serta perhitungan 4 metrik jarak utama.

## 📄 Berkas Pembelajaran
1. `01_vector_space_and_math.py`: Demonstrasi representasi teks ke vektor, penjumlahan/pengurangan vektor (Raja - Pria + Wanita = Ratu).
2. `02_distance_metrics.py`: Kalkulator Cosine Similarity, Dot Product, Euclidean (L2), dan Manhattan (L1).
3. `03_normalization_and_dimensions.py`: Simulasi L2 Normalization dan pemotongan dimensi Matryoshka Embeddings.

## 🚀 Cara Menjalankan
```bash
python3 01_embedding_fundamentals/01_vector_space_and_math.py
python3 01_embedding_fundamentals/02_distance_metrics.py
python3 01_embedding_fundamentals/03_normalization_and_dimensions.py
```
