# 04. RECOMMENDATION SYSTEMS (SISTEM REKOMENDASI)

Modul ini mempelajari penerapan **Embeddings** untuk Sistem Rekomendasi item-to-item, pembuatan vektor profil pengguna, dan ranking Top-N.

## 📄 Berkas Pembelajaran
1. `01_content_based_recommender.py`: Rekomendasi item serupa (Content Filtering) berbasis kemiripan vektor produk.
2. `02_user_profile_vector_aggregation.py`: Penggabungan riwayat interaksi pengguna menjadi satu vektor profil sintetis.
3. `03_top_n_item_ranking.py`: Ranking rekomendasi Top-N menggabungkan kemiripan vektor + skor popularitas item.

## 🚀 Cara Menjalankan
```bash
python3 04_recommendation_systems/01_content_based_recommender.py
python3 04_recommendation_systems/02_user_profile_vector_aggregation.py
python3 04_recommendation_systems/03_top_n_item_ranking.py
```
