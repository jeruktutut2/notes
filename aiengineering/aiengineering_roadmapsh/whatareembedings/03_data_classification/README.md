# 03. DATA CLASSIFICATION & CLUSTERING

Modul ini mempraktikkan klasifikasi intent, zero-shot classification, dan clustering topik otomatis menggunakan embeddings.

## 📄 Berkas Pembelajaran
1. `01_embedding_intent_classifier.py`: Pelatihan Logistic Regression cepat di atas fitur vektor embedding.
2. `02_zero_shot_classification.py`: Klasifikasi zero-shot berbasis kemiripan Cosine Similarity label vs teks tanpa training data.
3. `03_semantic_clustering_kmeans.py`: Topic Modeling dan pengelompokan dokumen otomatis menggunakan K-Means pada ruang vektor.

## 🚀 Cara Menjalankan
```bash
python3 03_data_classification/01_embedding_intent_classifier.py
python3 03_data_classification/02_zero_shot_classification.py
python3 03_data_classification/03_semantic_clustering_kmeans.py
```
