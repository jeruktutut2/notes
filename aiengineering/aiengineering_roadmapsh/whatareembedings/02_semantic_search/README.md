# 02. SEMANTIC SEARCH (PENCARIAN SEMANTIK)

Modul ini mendalami implementasi **Semantic Search**, teknik chunking dokumen, serta Hybrid Search dengan RRF.

## 📄 Berkas Pembelajaran
1. `01_keyword_vs_semantic_search.py`: Perbandingan langsung pencarian kata kunci biasa vs pencarian berbasis kemiripan semantik vektor.
2. `02_chunking_and_embedding_pipeline.py`: Strategi memotong dokumen panjang (chunking) dan membangun pencarian index vektor.
3. `03_hybrid_search_bm25_dense.py`: Penggabungan Lexical Search + Vector Search menggunakan Reciprocal Rank Fusion (RRF).

## 🚀 Cara Menjalankan
```bash
python3 02_semantic_search/01_keyword_vs_semantic_search.py
python3 02_semantic_search/02_chunking_and_embedding_pipeline.py
python3 02_semantic_search/03_hybrid_search_bm25_dense.py
```
