# 🛠️ Modul 03: Implementing RAG

Submodul ini mencakup 5 langkah utama implementasi pipeline RAG secara langsung:
1. `01_chunking_strategies.py`: Pemotongan dokumen (Fixed, Sentence, Recursive).
2. `02_embedding_generation.py`: Generasi Dense Vector Embeddings.
3. `03_vector_database_storage.py`: Penyiapan Index & Payload Metadata Vector DB.
4. `04_retrieval_process.py`: Similarity Search, Hybrid Search (Dense + BM25) & Metadata Filter.
5. `05_generation_synthesis.py`: Context Prompting, Synthesized Generation & Citations.

## 🚀 Cara Menjalankan

```bash
python3 03_implementing_rag/01_chunking_strategies.py
python3 03_implementing_rag/02_embedding_generation.py
python3 03_implementing_rag/03_vector_database_storage.py
python3 03_implementing_rag/04_retrieval_process.py
python3 03_implementing_rag/05_generation_synthesis.py
```
