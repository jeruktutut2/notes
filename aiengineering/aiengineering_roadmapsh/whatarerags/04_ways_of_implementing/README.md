# 🧱 Modul 04: Ways of Implementing RAG

Submodul ini membahas 5 cara utama pengimplementasian RAG:
1. `01_using_sdks_directly.py`: Pure Python / direct SDK implementation tanpa framework.
2. `02_langchain_rag.py`: LangChain chains & retrievers.
3. `03_llamaindex_rag.py`: LlamaIndex vector store index & query engine.
4. `04_haystack_and_ragflow.py`: Haystack pipeline architecture & RAGFlow agentic parsing.

## 🚀 Cara Menjalankan

```bash
python3 04_ways_of_implementing/01_using_sdks_directly.py
python3 04_ways_of_implementing/02_langchain_rag.py
python3 04_ways_of_implementing/03_llamaindex_rag.py
python3 04_ways_of_implementing/04_haystack_and_ragflow.py
```
