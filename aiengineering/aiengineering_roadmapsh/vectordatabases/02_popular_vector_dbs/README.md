# Modul 02: Popular Vector Databases (Pick One)

Modul ini membedah **Ekosistem Vector Databases Utama** sesuai diagram roadmap:

## 📂 Berkas Pembelajaran
1. `01_pinecone_hands_on.py`: Hands-on integrasi **Pinecone** (Pilihan utama / Highlighted di Roadmap), Serverless indexing, namespaces, upserting & metadata filtering.
2. `02_chroma_db_hands_on.py`: Integrasi **Chroma DB** persistent client & collections untuk local development.
3. `03_faiss_hands_on.py`: Hands-on **FAISS** (FlatL2, IVFFlat, HNSWFlat) untuk in-memory fast vector similarity search.
4. `04_ecosystem_comparison.py`: Matriks komparasi mendalam antara Pinecone, Chroma, FAISS, Weaviate, LanceDB, Qdrant, Supabase pgvector, & MongoDB Atlas.

## 🚀 Cara Menjalankan
```bash
python3 01_pinecone_hands_on.py
python3 02_chroma_db_hands_on.py
python3 03_faiss_hands_on.py
python3 04_ecosystem_comparison.py
```
