# Modul 01: Purpose and Functionality

Modul ini berfokus pada **Tujuan Utama & Fungsionalitas Vector Databases**:

## 📂 Berkas Pembelajaran
1. `01_vector_db_vs_traditional_db.py`: Menguji perbandingan cara kerja pencarian persis SQL tradisional vs pencarian vektor kemiripan semantik.
2. `02_distance_metrics_and_payloads.py`: Mengkalkulasi 3 metrik jarak (Cosine Similarity, Dot Product, Euclidean L2) dan mengeksekusi pencarian vektor dengan filter metadata payload.

## 🚀 Cara Menjalankan
```bash
python3 01_vector_db_vs_traditional_db.py
python3 02_distance_metrics_and_payloads.py
```
