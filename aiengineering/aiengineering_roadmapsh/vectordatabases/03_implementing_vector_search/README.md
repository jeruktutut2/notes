# Modul 03: Implementing Vector Search

Modul ini membedah **Pengindeksan Vektor** dan **Eksekusi Pencarian Kemiripan**:

## 📂 Berkas Pembelajaran
1. `01_indexing_embeddings_hnsw_ivf.py`: Visualisasi & simulasi algoritma pengindeksan HNSW (Hierarchical Navigable Small World) vs IVF (Inverted File Clustering) vs Exact Flat Scan.
2. `02_performing_similarity_search.py`: Hands-on pencarian kemiripan vektor, metadata pre/post filtering, dan Hybrid Search (BM25 + Dense Vectors).

## 🚀 Cara Menjalankan
```bash
python3 01_indexing_embeddings_hnsw_ivf.py
python3 02_performing_similarity_search.py
```
