Transport Layer: Stdio vs SSE / HTTP

Pelajari perbedaan mendasar antara komunikasi saluran lokal Stdio dan saluran remote SSE.

📟 Stdio Transport (Local Subprocess)

Sangat Cepat

Menggunakan pipe stdin dan stdout dari subprocess lokal. Setiap pesan JSON-RPC diakhiri baris baru (\n).

Pilih tombol untuk mensimulasikan...
  • ✅ Tidak membutuhkan Port Jaringan / Firewall
  • ✅ Sangat aman (terisolasi di mesin lokal)
  • ❌ Hanya bisa berjalan di mesin yang sama

🌐 SSE / HTTP Transport (Remote Cloud)

Cloud & Remote

Menggunakan HTTP GET untuk Server-Sent Events stream (Server -> Client) dan HTTP POST (Client -> Server).

Pilih tombol untuk mensimulasikan...
  • ✅ Dapat diakses antar server melalui internet
  • ✅ Mendukung autentikasi Bearer Token & TLS/HTTPS
  • ❌ Membutuhkan manajemen port & koneksi jaringan
