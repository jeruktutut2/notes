# Subtopik 2: Open Source & Open Weights Models

Modul ini mempelajari keluarga model terbuka (*Open Weights*) populer di industri:
1. `01_meta_llama.py` - Keluarga Meta Llama 3.1 & 3.2 (1B s/d 405B), lisensi, dan rekomendasi deployment.
2. `02_deepseek_models.py` - Arsitektur DeepSeek V3 & R1 (MoE, Reinforcement Learning CoT, Distillation).
3. `03_qwen_multilingual.py` - Spesialisasi Alibaba Qwen 2.5 (Multilingual, Qwen-Coder, Qwen-Math).
4. `04_google_gemma.py` - Kinerja Google Gemma 2 (2.7B, 9B, 27B) pada perangkat lokal/edge.

## Cara Menjalankan Script
```bash
python3 02_open_source_models/01_meta_llama.py
python3 02_open_source_models/02_deepseek_models.py
python3 02_open_source_models/03_qwen_multilingual.py
python3 02_open_source_models/04_google_gemma.py
```
