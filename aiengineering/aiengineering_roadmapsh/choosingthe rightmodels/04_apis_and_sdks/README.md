# Subtopik 4: APIs & SDKs

Modul ini mempelajari spesifikasi API dan SDK resmi masing-masing provider:
1. `01_openai_response_api.py` - OpenAI Response API, Structured Outputs, dan Function Calling Tool Specs.
2. `02_claude_messages_api.py` - Anthropic Claude Messages API, System Prompt, dan Content Block Handling.
3. `03_gemini_api_integration.py` - Google Gemini SDK, Multimodal Payload, dan Safety Settings.
4. `04_hf_inference_sdk_and_compat.py` - Hugging Face Inference SDK & Building OpenAI-Compatible Servers.

## Cara Menjalankan Script
```bash
python3 04_apis_and_sdks/01_openai_response_api.py
python3 04_apis_and_sdks/02_claude_messages_api.py
python3 04_apis_and_sdks/03_gemini_api_integration.py
python3 04_apis_and_sdks/04_hf_inference_sdk_and_compat.py
```
