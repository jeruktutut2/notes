# Subtopik 3: Platforms & Ecosystem

Modul ini mempelajari platform penyedia, hub model, runtime lokal, dan API gateway:
1. `01_huggingface_hub_and_tasks.py` - Hugging Face Tasks, Hub API discovery, dan metadata model card.
2. `02_transformers_js_web.py` - Konsep dan kode runner Transformers.js untuk client-side browser AI.
3. `03_ollama_and_lmstudio.py` - Pengelolaan local runtime Ollama REST API & LM Studio local server.
4. `04_openrouter_unified_gateway.py` - Unified model routing & automatic fallback via OpenRouter API.

## Cara Menjalankan Script
```bash
python3 03_platforms_and_ecosystem/01_huggingface_hub_and_tasks.py
python3 03_platforms_and_ecosystem/02_transformers_js_web.py
python3 03_platforms_and_ecosystem/03_ollama_and_lmstudio.py
python3 03_platforms_and_ecosystem/04_openrouter_unified_gateway.py
```
